# norioWork 首页设计验收

final result: passed

## 当前目标

2026-11-16 用户要求顶部只保留「首页」和跳转下载页的「下载」按钮，并重新规划首页、提高整体质感。本轮是已有页面的重新设计，沿用 Octop 参考中的克制导航、大幅产品界面与留白，按新要求移除多入口、暖色颗粒、标题吉祥物和浮动卡片，不再以逐像素复刻旧参考作为验收标准。

## 结构和视觉

- 顶部与页脚均仅有首页、下载；手机直接呈现两个入口，无额外菜单。
- 首页顺序：主张与产品预览 → 三个特色场景 → AI 与编辑器协同 → 下载。
- 暖白首屏、灰绿产品画框、米色 PPT 展示、浅绿/灰紫转换场景、深绿编辑区。
- 电脑主标题 68px，手机 37px，320px 下 31px；主按钮统一深色，下载路径统一为 `/download/`。
- 旧文档和更新日志路径保留兼容，移出导航。安装步骤仅放在下载页。

## 已验证

- 首页三个产品预览：点击 Excel、End 键切换文档、切回 PPT，面板与选择状态同步。
- 图片放大显示正确文件；Escape 关闭原生对话框。
- 手机导航「下载」进入 `/download/`，Windows 安装包及 GitCode 发行链接正确呈现；Linux 如实显示尚未发布。
- 320、390、768、1280px 无横向溢出；桌面完整页面和手机首屏/功能区已目视检查。
- 浏览器无错误或警告。
- 5 个 HTML 文件、103 个本地资源/锚点引用及 ARIA 目标校验通过。
- `npm run check`、`npm run build`、`git diff --check` 通过；源码内部设计证据不进入构建。

## 素材与能力边界

本轮没有生成新图。品牌、文件图标、客户端截图与内置 PPT 风格来自已有产品素材；箭头与关闭图标来自 Lucide，许可证保留。照片为文字识别场景示例，旁边的文档结果标签为网站说明，不是在线识别结果。图表识别依赖识图模型，拍照文字可使用识图模型或可用 OCR；官网本身不执行生成。历史海岸摄影与颗粒背景保留文件但当前首页不引用。当前未发现阻断预览的问题。
