# 小蓝办公扩展首页设计验收

final result: passed

日期：2026-11-17。此报告覆盖新增内容版，前一版验收存于 `docs/design-evidence/blue-home-base-qa.md`。

## 视觉基准与证据

- 来源：用户最新提供的 `docs/design-evidence/extended-home-reference.png`，1024×1536。
- 实现：`http://localhost:3000/`；`docs/design-evidence/extended-home-desktop.jpg`，1024×1537。
- CSS视口1024×1536，截图密度1 CSS像素对应1图像像素；无设备边框。实现全页比参考高1px，无需密度归一化。
- 状态：首页选中、FAQ收起、无详情弹层。
- 全图并排：`docs/design-evidence/extended-home-comparison.jpg`；新增内容局部：`extended-home-details-comparison.jpg`。两张均已打开检查，参考与实现位于同一输入中。
- 响应式证据：`extended-home-mobile.jpg`（390×844）、`extended-home-mobile-full.jpg`、`extended-home-tablet.jpg`（768×1024）、`extended-home-wide.jpg`（1448px宽全页）。手机没有单独视觉稿，按原有信息层级适配，不声称像素还原。

## Findings

没有剩余可行动的 P0/P1/P2 问题。此轮第一次同尺寸视觉对照通过；没有用构建或调试次数冒充视觉迭代。

五项必检表面：

1. **字体与文字层级**：沿用 Microsoft YaHei / PingFang SC / 系统字体。1024px下主标题43px、蓝色第二行50px，区块标题26px，卡片标题13–16px；详情和主要说明使用真实HTML文字。标题换行、导航选中、卡片行高与参考层级一致。手机主标题35/43px、两列卡片，中文没有截断。
2. **间距与布局节奏**：54px导航、360px首屏、56px能力条、四列场景、三列两行能力、四列优势与人群、底部下载和FAQ，总高1537px。新增区域整体位置与参考接近。390px下场景、能力、优势及人群改两列，FAQ一列；768px主视觉改上下结构。320、390、768、1024和1448px无全页横向滚动，抽查卡片及下载选项无局部越界。
3. **颜色与视觉标记**：蓝白背景、蓝色主按钮、白卡片、浅蓝细边与阴影保持一致。优势图标采用黄/蓝强调，FAQ有展开箭头和清晰焦点状态。波浪使用现有生成图片，没有用网页元素描摹参考插画。
4. **图像与素材质量**：保留上一版蓝色机器人与真实客户端内容组成的主视觉，新增四张独立生成的透明角色WebP，部署资产均位于项目内。角色缩至76px仍可辨认，透明边缘自然。手机向下浏览后可见图片均成功加载；详情中无src的隐藏图片不算失败资源。新增图标来自既有Lucide系统，产品图标沿用客户端资产。
5. **文案与能力范围**：新增产品优势、四类人群、系统下载区及三项FAQ。没有照搬参考中尚未得到发布配置支持的macOS下载承诺，统一显示待发布。Windows入口标x64，不虚构操作系统最低版本。将「数据不出本地」改为桌面创作与文件管理说明，避免与云模型使用方式冲突。场景文案用纸质表格取代成绩单。版权年份为2026。

## 交互与实现验证

- 新增六项能力快捷条复用现有详情弹层；实测个人知识库弹层显示对应标题、隐藏图片，Escape关闭。
- FAQ实测点击第一项展开，再对第二项按Enter；第一项自动收起，第二项展开。再次Enter可收起。
- 首页macOS入口进入 `/download/?platform=macos`，macOS标签被选中并显示尚未发布；Windows入口进入对应标签。
- 非法平台参数 `__proto__` 回退Windows，不访问继承属性。
- Windows主链接仍是 `https://gitcode.com/cgq2100/norioWork/releases/latest`，跳转GitCode最新正式版发行页，由访客选择安装包；没有重新写死版本、日期或大小。
- 浏览器控制台错误及警告均为空。
- 123个本地链接/资源验证通过，四张新增WebP进入dist，构建HTML正确引用带哈希的首页资源，内部设计证据没有发布到dist。
- `npm run check`、`npm run build`、`git diff --check`通过。npm环境已有home配置警告不影响构建。

## 有意差异与后续P3

- 本轮为追加内容，保留已完成的产品主视觉和四张场景图；不替换成参考中的真人首屏或人形吉祥物。
- 新增人群角色为原创替代，不复制参考人物；产品图标保持真实产品颜色与样式。
- 标题两侧延续已有引用装饰，未逐像素复制参考短斜线。属于P3装饰差异。
- macOS/Linux发布后，可更新下载配置及首页待发布文案；当前不提供无效安装包链接。
