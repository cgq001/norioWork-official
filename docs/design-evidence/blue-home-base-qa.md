## 五项必检表面

1. **字体与文字层级**：使用 Microsoft YaHei / PingFang SC / 系统无衬线字体；桌面主标题 48px、字重 800，副文案 18.5px；区块标题 28px；导航 16px。字体与参考的中文粗细和信息层级相近，AI 图片中的字形不作为网页字体来源。卡片正文、标题、导航均为真实 HTML 文字。
2. **间距与节奏**：54px 导航、300px 首屏、四列场景、六列能力、120px 品牌横幅与48px页脚，桌面整体高度约1086px，与选定参考的主要区块比例一致。四场景网格间距22px，六能力网格间距15px；边距、圆角与阴影已同图检查。平板主视觉改为上下结构，避免图文交叠。
3. **颜色与视觉标记**：蓝白背景、深蓝文字、蓝色下载按钮、白色卡片、细蓝边框与轻阴影。轮廓图标已修正为蓝色，导航选中状态有蓝色下划线。波浪背景为新生成的图片，没有用网页元素描摹原图插画。
4. **图像与素材质量**：七张新图全部使用内置 ImageGen 制作并在项目中保存；主视觉与页脚保留小蓝蓝白机器人品牌，四个摄影场景具有统一的蓝色服装、自然光与转换图形。所有图片已加载，无占位资源。首屏基于真实编辑器素材制作宣传插画，不能当成未加工截图；详情中的三个编辑器截图使用既有客户端素材并标注演示内容。透明边缘、场景裁剪和小尺寸清晰度已检查。
5. **文案与能力范围**：首页按参考呈现四个场景与六项能力；将成绩单示例替换为中性的项目明细，版权年份更新为2026。详情说明模型、OCR、识别核对等实际使用条件。官网不调用模型、不上传资料，也不伪装执行生成。导航继续只保留首页与下载。

## 发现与修正历史

- **第一轮 [P2] 图标颜色、首屏位置与卡片高度**：初稿轮廓图标呈黑色、文字与卡片高度略偏离参考。证据 `blue-home-desktop-before.jpg`。修正为蓝色 Lucide 原生图标，调整主标题、副文案和按钮间距，以及场景卡片行高；页脚角色移除透明留白以保证展示尺寸。最终桌面图与全图对照已复查。
- **第二轮 [P2] 768px 首屏图文重叠**：初稿仍采用并排布局，浮动文档图标压到文案。证据 `blue-home-tablet-before.jpg`。将1000px及以下首屏改为上下结构，1100px以下调整网格和字号；修正后证据 `blue-home-tablet.jpg`，图文清晰分开。
- **第三轮 [P2] 1280px 能力卡片文案越界**：局部文字宽168px、可用宽149px，虽无全页横向滚动，但文字超出卡片内容区。1380px以下调整字号与内边距，并允许自然换行。修正后浏览器检查所有能力说明 `scrollWidth <= clientWidth`，无局部越界；1448px整体比例不受影响。
- **最终比较**：重新生成并打开 `blue-home-comparison.jpg`，同尺寸全图和局部图未发现剩余可行动的 P0/P1/P2 问题。

## 有意的差异与 P3

- 用户允许自行设计图片，故宣传图与四个摄影场景为原创替代，机器人沿用实际小蓝形象，没有复制参考中的人形角色。
- 六项能力图标沿用已有产品图标，不强行统一成参考图里的紫色图标；轮廓图标来自现有 Lucide 库。
- 参考图的弧形下划线和抽象小装饰没有逐像素复刻；标题两侧采用蓝色原生引用图标。这些属于 P3 装饰差异，不影响本次版式、能力呈现和下载流程。
- 下载页继续沿用已验证的原有页面，本轮没有重新设计下载页或更改其固定最新版入口。
