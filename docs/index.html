小蓝办公使用指南

从连接模型到完成一份文档，了解如何用小蓝办公（norioWork）处理日常资料、写作和汇报。

本指南按当前客户端功能编写。安装包版本与平台支持见下载页。

认识小蓝办公

小蓝办公把 AI 对话、文档编辑和资料管理放在同一个桌面客户端。可以先在「对话」里梳理思路，也可以打开现有文档，在编辑器侧边继续提问和修改。

  • 对话与助手。直接向模型提问，或为写作、资料整理等用途配置助手和常用技能。
  • 文档与流程图。创建 Word、Excel、PPT 和智能文档，也可在流程图编辑器制作架构图或流程图。
  • 文件与知识。用资源库管理文件，用笔记保存内容，用知识库为 AI 回答提供可追溯的资料。

完成第一份文档

  1. 从下载页获取匹配系统和架构的安装包。Windows x64 安装完成后，从开始菜单打开「小蓝办公」。
  2. 进入「设置 → 模型」，按服务商的要求填写 API 地址和凭据，或使用该服务支持的登录方式。添加要用的模型并测试连接，再设置默认对话模型。
  3. 进入「对话」，上传参考材料并说明交付格式。已有文件也可以从资源库打开，再使用编辑器侧边的 AI 对话。
  4. 生成后点击「打开编辑」，检查内容，再按需要保存到资源库或导出本机文件。

试试从会议纪要生成项目计划

“根据这份会议纪要写一份 Word 项目计划。列出目标、阶段、负责人和待确认事项。没有明确日期的任务标记为待确认。”

四款文档编辑器

Word · .docx

撰写报告、方案或正式文档。可调整段落、标题和表格，也能选中指定段落，让 AI 润色、扩写或改成清单。

Excel · .xlsx

整理预算、待办清单和明细数据。选定工作表或单元格区域后，可以要求 AI 分类、汇总、补公式或调整选区格式。

PPT · .pptx

把资料整理成汇报大纲、幻灯片和配图。生成后可调整文字、图形和布局，也可以只修改当前页。

智能文档 · .nordox

适合项目笔记、手册与长资料整理。用标题、列表、表格和图片搭建结构，边看内容边与 AI 完善各章节。

在文档里和 AI 对话

  1. 指定范围。把光标放在插入位置，或选中段落、单元格和幻灯片，再打开 AI 对话。
  2. 写清要求。例如“把选中的段落改成三条项目目标，保留金额和截止日期”，或“把上一条回答插入当前文档”。
  3. 检查结果。核对改动范围、引用和数据。支持整轮撤回的编辑器可从回复下方查看修改记录或撤回本轮。

参考资料很长时

先让 AI 给出资料概况与章节清单，再按章节读取和输出。例如先整理前两章，并列出尚未处理的部分，核对之后继续。

插入绘图和 SVG

生成图片后，点击对话里的图片可在右侧预览。打开支持插图的文档并定位到光标或当前页，再点击「插入当前文档」。SVG 还可下载原文件。

管理和查找资料

  • 资源库适合管理上传文件、生成的作品和待复用资料。可以建文件夹、搜索名称、预览和导出文件。
  • 笔记适合记录会议纪要、灵感和工作记录。在对话输入框的更多工具里选择「引用笔记」，把需要的内容带到本轮对话。
  • 知识库适合组织产品手册、规范和项目资料。导入并解析文件后，在对话中选中知识库，可根据资料提问并打开引用的原文。

如果只想拿回某份原文件，可以说“把资源库里《客户交付清单.xlsx》发给我”。同时写明文件名和所在库，更容易找到正确文件。需要根据内容回答时，可以加上“引用原文出处”。

技能、通道与任务

按任务使用技能

内置技能可用于 PPT 创作、绘图、SVG 和文档编辑。也可以在「设置 → 个性化 → 技能」导入自己的技能。模型支持工具调用时，客户端可按任务使用已启用的相关技能。手动选定某项技能后，仍可按需调用负责其他环节的技能。

从常用消息应用发起请求

在「设置 → 通道」连接微信、QQ、企业微信、钉钉或飞书，按平台要求完成扫码或机器人配置。连接后可以通过通道发起对话，支持的通道可直接接收文件。文件超过通道上限时，回复会提示原因。

日程与定时任务

用「日程」管理安排与提醒，用「定时任务」为 AI 设置执行时间。例如每周整理一份工作简报，或按计划汇总指定资料。

常见问题

是否需要 API Key？

取决于所选服务。部分服务需要 API Key，支持账号授权的接入方式可按页面提示登录。本地 Ollama 可连接自己的本地模型。可用模型、额度和费用取决于服务商与账户。

能从 Windows 资源管理器直接打开文档吗？

使用包含文件关联功能的 Windows 安装包后，右键点击 .docx、.xlsx、.pptx 或 .nordox，选择「用小蓝办公打开」。Windows 11 可在「显示更多选项」中查找。文件会作为副本导入编辑。

资料会发给模型吗？

工作文件在客户端中管理。使用联网模型、联网搜索或消息通道时，完成请求所需的数据会发送给相应服务。处理敏感资料前，请核对所选模型、通道和引用范围。

网页里的演示能保存文档吗？

首页展示的是交互示意。创建、编辑与保存文档请使用桌面客户端。
